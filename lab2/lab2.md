# Лабораторная работа №2 по ООП

## Проектирование класса Vehicle

| Элемент | Описание |
| :--- | :--- |
| Имя класса | Vehicle |
| Поля | `brand` — марка автомобиля; `year` — год выпуска; `kilometers` — пробег; `engineStarted` — состояние двигателя; `status` — состояние автомобиля; `objectCount` — количество существующих объектов |
| Конструкторы | Конструктор без параметров; конструктор с маркой и годом; конструктор с маркой, годом, пробегом и состоянием |
| Методы чтения | `getBrand()`, `getYear()`, `getKilometers()`, `isEngineStarted()`, `getStatus()`, `printInfo()` |
| Методы изменения | `startEngine()`, `stopEngine()`, `drive()`, `breakCar()`, `repairCar()` |
| Инварианты | Пробег не может быть отрицательным; расстояние движения должно быть больше нуля; сломанный автомобиль не может ехать и запускать двигатель; автомобиль не может ехать при выключенном двигателе; год выпуска должен находиться в допустимом диапазоне |
